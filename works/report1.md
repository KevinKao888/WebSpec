# 期末書面報告(20%)

## 報告目標
1. 依照課程前8週課程內容，統整重點內容並展示多頁網頁成果
2. 為了規範大家回答的範圍，請依照五大主題和各項問題回答

## 操作流程

### 一、GitHub登入：
1. 登入(Sign in)：[https://github.com/signin](https://github.com/signin)
   - 使用Google帳號：![](../images/ContinueWithGoogle.png)

### 二、使用VSCode複製GitHub上2個儲存庫Repo
1. 使用 VS Code「檔案 → 開啟資料夾」，開啟資料夾：`D:\Web`
2. 開啟終端機，輸入git指令，設定GitHub帳號資訊
```shell
git config --global user.email [輸入EMail信箱]
```
```shell
git config --global user.name [輸入GitHub帳號]
```
3. 由GitHub複製Repo：WebSpec_學號、WebPage_學號
- GitHub網址：https://github.com/(GitHub名稱)/WebSpec_學號
- GitHub網址：https://github.com/(GitHub名稱)/WebPage_學號
```shell
git clone [貼上WebSpec網址]
```
```shell
git clone [貼上WebPage網址]
```

### 三、建立並修改期末書面報告 report1.md
1. 建立 WebSpec_學號/reports/report1.md。
2. 複製以下期末書面報告範本，於 report1.md 中貼上內容。
3. 填寫基本資料後，回答以下五個題目中，每個項目的問題。
4. 完成後儲存檔案。
5. 提交並推送該檔案。
6. 登入 GitHub 平台後，檢查 WebSpec_學號/reports/report1.md 內容。

```markdown
# 書面報告(20%)
- 學號：
- 姓名：
- 信箱：

## 內容規範
1. 書面報告繳交至 GitHub Repo /WebSpec_學號/reports/report1.md
2. 繳交的 report1.md 需要用 Markdown 的格式撰寫，可使用AI工具輔助
3. 撰寫的內容請以課堂中用到的為主，也可以補充課堂中未提到的內容
4. 每項問題字數約100-200字，盡可能以清單、表格或圖表方式呈現
5. 題目共12小題，轉為簡報後，每1題1頁，含封面，總頁數13頁，最多15頁
6. 網頁製作(3-5頁)成果請展示網頁規格及網頁截圖，並附上成果網址

### 一、GitHub(5%)
1. GitHub有什麼基本功能和用途？
2. GitHub的版本控制如何操作？
3. GitHub如何做到獨立網址發佈？

### 二、VSCode和AITool(5%)
1. VSCode課程中擴充元件有哪些？作用為何？
2. AI工具常見有哪些？請比較其差別？
3. AI工具如何用提示詞製作網頁和規格？

### 三、網頁製作(5%)
1. 運用AI由規格製作網頁的流程為何？
2. 展示多頁網頁的實作網頁大綱規格內容？
3. 展示多頁網頁的實作網頁預覽截圖內容？

### 四、心得報告(5%)
1. 本課程的學習心得及感想為何？
2. 運用AI工具製作網頁有什麼優缺點？
3. 課程、作業、考試及報告有何建議？

### 五、參考資料(不計分)
1. 請列舉資料來源，如網址、AI工具等
```

### 四、評分標準
1. 評分項目及配分
- 每個主題獨立評分，以 1 分為級距。有相關實質內容至少給予 1 分，因此有效分數為：**0、1、2、3、4、5 分。**

| 評分主題              | 題數     | 最低分   | 最高分    |
| ----------------- | ------ | ----- | ------ |
| 一、GitHub          | 3      | 0     | 5      |
| 二、VSCode 和 AITool | 3      | 0     | 5      |
| 三、網頁製作            | 3      | 0     | 5      |
| 四、心得報告            | 3      | 0     | 5      |
| 五、參考資料            | —      | —     | 不計分    |
| **合計**            | **12** | **0** | **20** |

2. 各主題共用評分標準
- 以下評分標準如下：

| 得分    | 評分等級 | 評分標準                                    |
| ----- | ---- | --------------------------------------- |
| **5** | 優異   | 三題皆完整回答，內容正確、具體且有深度，具有適當的實作、案例、比較或個人分析。 |
| **4** | 優良   | 三題皆有充分回答，內容大致完整正確，僅少部分內容需要加強。           |
| **3** | 良好   | 有基本且正確的觀念，回答具有一定完整性，但缺少部分細節、案例或深入說明。    |
| **2** | 普通   | 有相關基本內容，但說明較簡略、完整性不足，或多數問題未充分回答。        |
| **1** | 基本   | 至少具有可理解的相關實質內容，但整體內容明顯不足。               |
| **0** | 未完成  | 完全空白、只有題目標題、沒有實質回答，或內容與主題無關。            |

3. 各主題的具體評分重點
- 為避免 AI 僅依照字數或內容長度評分，建議另外制定各主題的具體判斷依據。

| 主題     | 基本評分重點          | 高分評分重點                  |
| ------ | --------------- | ----------------------- |
| GitHub | 基本功能、版本控制、Pages | 正確解釋操作流程、指令差異及發布方式      |
| VSCode 和 AITool | 擴充元件、工具比較、提示詞  | 說明各工具的實際用途，能比較工具差異，提供正向及逆向生成規格的提示詞    |
| 網頁製作   | 開發流程、網頁規格、成果截圖  | 展示完整的3～5頁網頁規格、實作截圖及成果網址 |
| 心得報告   | 學習心得、優缺點、課程建議   | 具有個人經驗、具體分析及建設性建議       |
