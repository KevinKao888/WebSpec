# 期末上台報告(20%)

## 報告目標
1. 透過 Gemini Notebook 將書面報告的md檔，製作簡報 PDF 檔
2. 透過 Canva 匯入簡報 PDF 檔，修改內容或增加頁面
3. 製作分享連結，知道連結的使用者即可瀏覽

## 操作流程

### 一、GitHub登入：
1. 登入(Sign in)：[https://github.com/signin](https://github.com/signin)
   - 使用Google帳號：![](../images/ContinueWithGoogle.png)

### 二、使用VSCode複製GitHub上2個儲存庫Repo
1. 使用 VS Code「檔案 → 開啟資料夾」，開啟資料夾：`D:\Web`
2. 開啟終端機，輸入git指令，設定GitHub帳號資訊
```shell
git config --global user.email [輸入EMail信箱]
```
```shell
git config --global user.name [輸入GitHub帳號]
```
3. 由GitHub複製Repo：WebSpec_學號、WebPage_學號
- GitHub網址：https://github.com/(GitHub名稱)/WebSpec_學號
- GitHub網址：https://github.com/(GitHub名稱)/WebPage_學號
```shell
git clone [貼上WebSpec網址]
```
```shell
git clone [貼上WebPage網址]
```

### 三、建立並修改期末上台報告 report2.md
1. 建立 WebSpec_學號/reports/report2.md。
2. 複製以下期末上台報告範本，於 report2.md 中貼上內容。
3. 填寫基本資料後，填寫簡報的網址連結。
4. 完成後儲存檔案。
5. 提交並推送該檔案。
6. 登入 GitHub 平台後，檢查 WebSpec_學號/reports/report2.md 內容。

```markdown
# 期末上台報告(20%)
- 學號：
- 姓名：
- 信箱：
- 簡報連結：

## 內容規範
1. 書面報告繳交至 GitHub Repo /WebSpec_學號/reports/report2.md
2. 透過 Gemini Notebook 將書面報告的md檔，製作簡報 PDF 檔
3. 透過 Canva 匯入簡報 PDF 檔，修改內容或增加頁面
4. 製作分享連結，設定任何具有此連結者，可供檢視，複製此連結
```

### 四、評分標準
1. 簡報內容評分標準(10%)
- 依據書面簡報內容製作簡報，以下各項缺內容則得0分。

| 評分項目 | 評分方式 | 分數 |
| --- | --- | ---: |
| 簡報封面及題目標題 | 封面含班級、學號、姓名得1分，上方標題需包含每1題的題目得1分 | **2 分** |
| GitHub內容修飾 | 僅用條列文字呈現得1分，以流程圖、表格、圖片等修飾等2分 | **2 分** |
| VSCode和AITool內容修飾 | 僅用條列文字呈現得1分，以流程圖、表格、圖片等修飾等2分 | **2 分** |
| 網頁製作內容修飾 | 僅用條列文字呈現得1分，以流程圖、表格、圖片等修飾等2分 | **2 分** |
| 心得報告內容修飾 | 僅用條列文字呈現得1分，以流程圖、表格、圖片等修飾等2分 | **2 分** |
| | 合計 | **10 分** |

1. 上台口頭報告評分標準(10%)
- 每位學生上台報告時間約 3 分鐘。
- 使用自己繳交的 PDF 簡報進行報告。
- 同樣採用五個評分項目，每項最高 2 分，方便教師在短時間內完成評分。
- 應以自己的理解及語言進行說明，避免全程照稿朗讀。
- 必須介紹自己實際完成的網頁作品。
- 鼓勵分享個人心得、問題解決經驗及創新應用。

| 評分項目        | 0 分         | 1 分            | 2 分               |
| ----------- | ----------- | -------------- | ----------------- |
| **內容掌握程度**  | 無法說明報告內容    | 能說明基本內容，但較依賴簡報 | 熟悉內容，能以自己的話說明     |
| **口語表達能力**  | 表達不清楚或無有效說明 | 基本清楚，但較不流暢     | 表達清楚、流暢且有條理       |
| **技術與實作說明** | 無技術或實作說明    | 能簡單介紹工具或作品     | 能清楚說明技術、製作流程及成果   |
| **報告態度與台風** | 未有效進行報告     | 態度認真，但較依賴稿件    | 準備充分、態度自然、適度與聽眾互動 |
| **時間掌握能力**  | 時間嚴重不足或超時   | 時間略有不足或超時      | 時間適當且完整說明重點       |
| **合計**      |             |                | **10 分**          |
