# 多頁網站製作：由簡略大綱到詳細規格

## 作業目標

- 修改網站簡略大綱，規劃自己的三頁網站。
- 使用 AI 生成風格一致、可以互相連結的三頁網頁。
- 使用 AI 逆向整理全站共用規格及各頁詳細規格。
- 透過修改 Markdown 規格，更新網站內容。
- 使用 Git 保存修改紀錄，將規格及網頁同步至 GitHub。

> [!important]
> 本次流程：sitemap.md → AI → 三頁 HTML＋共用 CSS → AI → site.md＋各頁詳細規格 → 修改規格 → AI → 更新原網站。
> sitemap.md 是學生修改的初步大綱；site.md 是網站完成後，由 AI 整理的共用詳細規格。
> 所有路徑中的「學號」均須換成自己的學號。提示詞中的資料夾名稱也須一併修改。

## 操作流程

### 一、開啟兩個儲存庫的上層資料夾

1. 確認電腦已安裝 VS Code、Git、AI 延伸模組及 Live Server，並完成 AI 工具登入。
2. 確認兩個儲存庫已複製到同一個上層資料夾，例如：
   - D:/Web/WebSpec_學號/
   - D:/Web/WebPage_學號/
3. 使用 VS Code「檔案 → 開啟資料夾」，開啟 D:/Web/。
4. 確認檔案總管能同時看到 WebSpec_學號 與 WebPage_學號。
5. 如果已有檔案修改，請先確認內容並提交；再分別同步兩個儲存庫的遠端變更。

### 二、建立本次操作紀錄

1. 將本流程檔放在 WebSpec_學號/works/multipage.md。
2. 填寫本檔最上方的學號、姓名及信箱。
3. 儲存檔案。

### 三、建立並修改網站簡略大綱 sitemap.md

1. 建立 WebSpec_學號/specs/sitemap.md。
2. 複製以下範本，修改為自己的網站主題。
3. 至少修改網站名稱、網站目的、目標對象、風格方向及三頁內容。
4. 本次先統一使用 index.html、about.html、contact.html 三個檔名。
5. 完成後儲存。此時尚不需要自行建立 site.md。

#### sitemap.md 範本

將以下程式碼區塊內的內容複製至 sitemap.md：

```markdown
# 網站簡略大綱與架構

## 1. 網站基本資料
- 網站名稱：藍天咖啡
- 網站目的：介紹品牌、經營理念與聯絡方式。
- 目標對象：喜歡咖啡與休憩空間的消費者。
- 網站語言：繁體中文。

## 2. 共用風格方向
- 整體風格：溫暖、自然、簡潔。
- 主要配色：咖啡棕、米白，搭配少量深綠色。
- 字體方向：清楚易讀的繁體中文無襯線字體。
- 三頁使用一致的導覽列、頁尾、按鈕及卡片樣式。
- 支援電腦與手機瀏覽。
- 具體色碼、字級與間距由 AI 依此方向設計。

## 3. 網站架構
| 頁面 | 檔名 | 用途 |
|---|---|---|
| 首頁 | index.html | 呈現主題與主要特色 |
| 關於我們 | about.html | 介紹故事與理念 |
| 聯絡我們 | contact.html | 提供聯絡與交通資訊 |

## 4. 共用內容
- 導覽列：品牌名稱、首頁、關於我們、聯絡我們。
- 品牌名稱連回首頁。
- 標示目前所在頁面。
- 手機版提供可展開及收合的選單。
- 頁尾：品牌名稱、頁面連結、版權文字。
- 品牌標語：讓咖啡，陪你慢下來。

## 5. 首頁大綱
- 主視覺：咖啡主題圖片。
- 主標題：一杯咖啡，留一點時間給自己。
- 簡介：在熟悉的香氣裡，找到自己的生活節奏。
- 按鈕：認識我們、聯絡我們，連至對應頁面。
- 品牌簡介：介紹品牌特色。
- 三項特色：精選咖啡豆、用心烘焙、自在空間。

## 6. 關於我們大綱
- 頁面標題與簡介。
- 品牌故事：成立起點。
- 經營理念：三項品牌堅持。
- 環境介紹：圖片搭配文字。
- 按鈕：前往聯絡我們。

## 7. 聯絡我們大綱
- 頁面標題與簡介。
- 地址：待補
- 電話：待補
- Email：待補
- 營業時間：待補
- 有實際地址後，才建立 Google 地圖連結。
- 有電話及 Email 後，才建立撥號與寄信連結。
- 本次不建立聯絡表單。

## 8. 文案與素材規則
- 以學生提供的文字為優先。
- 未提供的介紹文字可由 AI 撰寫示範文案，列出供學生確認。
- 不可編造真實地址、電話或 Email。
- 優先使用學生提供的圖片，未提供時使用本地佔位圖。
- 圖片需要替代文字。

## 9. 輸出位置
- 網頁資料夾：WebPage_學號/multipage/
- 三頁 HTML 放在同一層。
- 共用 CSS：assets/css/site.css
- 共用 JavaScript：assets/js/site.js（有需要時建立）
- 圖片資料夾：assets/images/
- 內部連結與素材使用相對路徑。
```

### 四、使用 AI 生成三頁網站

1. 使用 VS Code 開啟 WebSpec_學號/specs/sitemap.md。
2. 開啟 AI 側邊對話框。
3. 將以下提示詞中的「學號」換成自己的學號，再送出：

```text
請讀取 WebSpec_學號/specs/sitemap.md，
依據網站架構、風格方向與各頁大綱建立三頁靜態網站。

請先確認實際資料夾，建立：
- WebPage_學號/multipage/index.html
- WebPage_學號/multipage/about.html
- WebPage_學號/multipage/contact.html
- WebPage_學號/multipage/assets/css/site.css

如有需要，建立 assets/js/site.js 及 assets/images/ 下的本地佔位圖。

要求：
1. 使用一般 HTML、CSS、JavaScript。
2. 三頁共用同一份 site.css，維持字體、配色、版面與元件一致。
3. 導覽列及頁尾保持一致，並標示目前所在頁面。
4. 各頁依自己的內容大綱安排區塊。
5. 內部連結與素材使用相對路徑，支援放在子資料夾中。
6. 支援手機瀏覽，手機選單可操作。
7. 不編造聯絡資訊，不使用不存在的圖片路徑。
8. 若目標檔案已存在，先讀取再更新；保留其他作業資料夾。
9. 完成後列出已做的檢查、尚待確認項目與示範文案。
本次先建立網站，暫不建立詳細規格。
```

4. 若工具要求操作權限，確認操作對象是本次規格及網頁資料夾後，再允許執行。
5. 確認三頁 HTML 與共用 CSS 都已建立。

### 五、預覽並檢查三頁網站

1. 在 multipage/index.html 上按右鍵，選擇「Open with Live Server」。
2. 點擊導覽列，確認可以切換三個頁面並返回首頁。
3. 逐頁檢查字體、顏色、按鈕、導覽列及頁尾是否一致。
4. 縮小瀏覽器視窗，檢查手機選單、文字及圖片排列。
5. 確認沒有圖片破圖、錯誤連結或非預期的水平捲動。
6. 確認 AI 提供的示範文案，修改為自己想要的內容。
7. 如有問題，請 AI 修正並重新預覽；確認後再進行下一步。

### 六、使用 AI 逆向生成詳細規格

1. 在 AI 對話框輸入以下提示詞，並替換學號：

```text
請讀取 WebPage_學號/multipage/ 下的三頁 HTML、
共用 CSS 及 JavaScript，依實際完成的網站逆向整理詳細規格。

請建立：
1. WebSpec_學號/specs/site.md
   記錄實際色碼、字體、字級、字重、行高、版面寬度、
   間距、導覽列、頁尾、按鈕、卡片、手機版及共用互動規則。
   包含共用檔案位置與各頁規格索引。

2. WebSpec_學號/specs/pages/home.md
   記錄 index.html 的詳細規格。

3. WebSpec_學號/specs/pages/about.md
   記錄 about.html 的詳細規格。

4. WebSpec_學號/specs/pages/contact.md
   記錄 contact.html 的詳細規格。

各頁規格須記錄：
- 對應 HTML 的輸出位置
- 依循 ../site.md 的說明
- 區塊順序、實際文字、圖片路徑與替代文字
- 排列方式、按鈕、連結目的地、互動及手機版呈現

要求：
- 共用設計集中在 site.md，各頁內容集中在對應分頁規格。
- 規格須具體到足以支援後續修改網站。
- 與原 sitemap.md 不一致的地方，另列差異供我確認。
- 未完成的功能不可記為已完成。
- 保留 sitemap.md，本次只整理規格，不修改網頁。
```

2. 確認 site.md 與三份分頁規格都已建立。
3. 使用 VS Code「開啟側邊預覽」閱讀 Markdown。
4. 對照網站確認文字、圖片、連結及區塊順序。
5. 若有差異，確認預期內容後請 AI 修正。

> [!note]
> sitemap.md 保存初始大綱；site.md 管理共用詳細設計；
> home.md、about.md、contact.md 管理各頁內容。
> Markdown 是提供給 AI 閱讀的規格，瀏覽器實際載入的是 HTML、CSS 與 JavaScript。

### 七、修改分頁規格，再更新網頁

1. 開啟 WebSpec_學號/specs/pages/about.md。
2. 自行修改至少一段文字，並新增一個內容區塊，例如團隊介紹或品牌理念。
3. 儲存規格檔案。
4. 在 AI 對話框輸入：

```text
我已修改 WebSpec_學號/specs/pages/about.md。
請先讀取 WebSpec_學號/specs/site.md，
再比對更新後的 about.md 與
WebPage_學號/multipage/about.html，
依新規格更新原本網頁，只修改有差異的部分。

沿用共用風格；若需新增專屬樣式，限定其作用範圍。
若修改共用 CSS，請檢查對首頁與聯絡我們的影響。
完成後核對規格與網頁一致，並說明修改項目。
```

5. 重新預覽，確認新增區塊及文字已更新。
6. 此次直接更新 about.html，不必另存 about2.html。

### 八、練習全站共用風格修改

1. 開啟 WebSpec_學號/specs/site.md。
2. 選擇一項共用設定修改，例如主色、按鈕圓角或內文字級。
3. 儲存後輸入：

```text
我已修改 WebSpec_學號/specs/site.md 的共用設計。
請依更新後的規格調整 WebPage_學號/multipage/ 下的網站。
同步檢查三頁的共用樣式與手機版呈現，
保留各頁內容，核對網站與規格一致，並說明修改項目。
```

4. 逐頁確認三頁都已套用新的共用設定。
5. 如果只修改單頁文字或區塊，不需要修改 site.md。

### 九、提交並推送兩個儲存庫

1. 在 VS Code 原始檔控制中，分別選擇 WebSpec_學號 與 WebPage_學號。
2. 檢查本次修改的檔案。
3. 分別填寫版本說明、提交及推送。
4. 建議在完成初稿、整理規格與修改網站後，分別建立 Commit。
5. 版本說明範例：
   - 建立三頁網站大綱
   - 完成三頁網站與共用樣式
   - 整理共用及分頁詳細規格
   - 依規格新增關於我們內容
6. 到 GitHub 確認兩個儲存庫均已同步。
